# OSMF artwork

These files come from the official media pack of the Open Source Maintenance
Fee project, offered by the project for use by participating projects:
<https://opensourcemaintenancefee.org/opensourcesmaintenancefee-media-pack.zip>

| File here | Original file in the pack | Use |
|---|---|---|
| `osmf-mark.svg` | `SVG/osmf-logo.svg` | The mark alone |
| `osmf-wide-on-light.svg` | `SVG/osmf-logo-wide-light.svg` | Wide logo, dark lettering, for light backgrounds |
| `osmf-wide-on-dark.svg` | `SVG/osmf-logo-wide-dark.svg` | Wide logo, light lettering, for dark backgrounds |

The files are unmodified apart from renaming. The inline copy of the mark in
the web UI (`src/api/ui/index.html`) additionally has its ids and class names
prefixed with `osmf-` so they cannot collide with the page.

The OSMF name and logo belong to the Open Source Maintenance Fee project.
