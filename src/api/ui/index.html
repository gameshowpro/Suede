Projection

The overlaps come from the layout above: drag the displays so they overlap exactly as the beams do on the wall — every seam its own amount. Suede renders the app once into that canvas and slices it per projector; with blending on, each seam is faded from both sides so the doubled light adds up to one seamless picture.

These settings are inactive: no displays overlap in the layout above. With no overlaps there is nothing to blend, so the displays are tiled directly and none of this applies. Position displays so they overlap — as the projector beams do on the wall — and blending engages.

Gamma shapes the fall-off — the projectors' transfer curve, usually 2.2. If seams glow on dark scenes (projector black is not zero light), raise the compensation until the rest of the picture matches them.

Managed applications

One application is active at a time, and it always covers the whole canvas — every display, with the overlaps handled by Suede. The rest of the list is a library to switch between.
